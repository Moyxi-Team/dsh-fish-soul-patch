# 文案人味改造（voice-tone）2026-11-14

问题：希希在 QQ 私聊、B站/抖音动态、抖音私信里频繁用「刚刷到个 xxx」起手，一开口就是模板腔。

根因不是人格卡，是**提示词输给了模型一个成品壳**：素材行写成「你刚在 B站刷到一个视频：」「你刚在抖音刷到一个视频：」，
主动开口的由头写成「你刚在 X 刷到一个视频《…》，你看完觉得：…」，她照着壳填内容，于是每条都从「刷到」开始。
另外 `social_post` / `memory` 里存下来的印象也带这层壳，回流到动态题材时再次强化。

## 改了什么（6 个文件、8 处）

| 文件 | 位置 | 改动 |
| --- | --- | --- |
| `lib/browse.js` | `promptFor()` | 素材首行「你刚在 B站刷到一个视频：」→「素材（B站信息流里的一条，你正在往下划）：」；感受要求下新增反套话起手约束 |
| `lib/douyin-browse.js` | `promptFor()` | 同上（抖音版） |
| `lib/life.js` | `queueShare()` | 分享由头不再写「你刚在 X 刷到一个视频《…》，你看完觉得：…」，改为「素材…你当时的反应…」，并明确禁用「刷到/看到/刚发现/给你分享」起手、禁止复述标题 |
| `lib/life.js` | `runDream()` | `missedPending.reason` 要求写成具体话点，禁止「刷到个视频给他看」这类空壳 |
| `lib/social.js` | `postPrompt()` | `mine`/`watched` 取出后**剥掉「我在 X 刷到《…》：」这层壳**，只留她当时的印象（否则模型照壳写）；保留已有的开头禁词表与「最近开头」展示 |
| `lib/social.js` | `bannedOpening()` 新增 + `post()` | 新增套话开头判定（刚刷到/刷到个/刷到一个/看到一个/刚刷完…，允许前面带「我/刚才/今天/最近」）；命中与「撞最近开头」合并为一次重写，各只重写一次，避免吞动态 |
| `lib/gateway.js` | `triggerProactive()` | 主动开口触发文案：`理由：` → `由头（仅供你想说什么，不要复述）：`，并加入「别用刚刷到/看到个/给你分享这类开头、别交代你怎么知道的、别搬由头原句」 |
| `lib/gateway.js` | `triggerDouyinProactive()` | 抖音私信跟卡片那句：加入禁用起手，并把「就着这条视频本身说」落到「从被戳到的那一点说起」 |
| `assets/douyin-proactive.js` | `draft()` | base 文件已同步：视频说明不再出现「把刚刷到的一个视频单独发过去」，改为「这句话旁边会配一条视频」；新增禁用起手 |
| `lib/index.js` | 聊天上下文注入块 | 标签「[你最近在 B站/抖音刷到的…]」→「看过的」，括号里补「别提你是怎么知道的」（标签本身也会被模型模仿成句型） |

## 效果边界

- 动态侧有**硬校验**：`bannedOpening()` 命中即重写，第二次仍命中才放行 —— 动态基本不会再以「刚刷到」开头。
- 主动开口 / 分享语由会话模型写，属提示词级约束（无硬校验），靠「不再给成品壳 + 明示禁用起手」压低复发率；若仍复发，下一步在出站前加同款 `bannedOpening` 拦截重写。

## 生效条件

改的是 `node_modules/dsh-fish-soul/lib/*`，需要 **重启 DSH（或插件重载）** 才生效。
