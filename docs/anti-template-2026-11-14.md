# P12 anti-template：主动说话别再「刚看到个」起头

- 日期：2026-11-14
- 插件版本：dsh-fish-soul 0.15.55
- 补丁段：`P12 anti-template`（`assets/anti-template-hunks.json`，5 处锚点）
- 重放：`node patch-fish-soul.mjs` 或 `node patch-fish-soul.mjs --only anti-template`

## 为什么还有这个问题

11-14 早先那轮 voice-tone（`docs/voice-tone-2026-11-14.md`）只改了 6 个文件的开口措辞和基线，**没有覆盖「主动说话」这条链路**，根因四处：

1. `lib/gateway.js` 主动开口提示词只列了「刚刷到 / 刷到个 / 看到个」，**漏了「刚看到个」「刚看到一个」** —— 模型正好从这个缝里钻。
2. `lib/life.js` 分享由头写的是「素材（不是让你复述这段…）」「你要把这个链接发给对方」，措辞偏「上一条视频 / 链接」的指令感，模型顺手就写成「刚看到个」来交代来源。
3. `lib/social.js` 的出站套话检测（`bannedOpening`）正则只认「刷到 / 看到一个 / 发现」，**「刚看到个」「看了个」「瞅见」「听说」全部漏检**，所以即使模型犯规也没有任何兜底改写。
4. `lib/behavior.js` 只有「别用括号写神态」「别客套」这类风格约束，**没有一条明确禁止交代消息来源**。

## 改了什么

| 文件 | 位置 | 改动 |
| --- | --- | --- |
| `lib/behavior.js` | 人格提示词（`[说话方式]` 之后） | 新增 `[别交代来源]`：不许用「刚看到、刚刷到、刚发现、刚听说、今天看到、最近刷到」起头讲看到的事，也不许交代消息从哪儿来；直接说那件事本身或此刻在干嘛 |
| `lib/gateway.js` | 主动开口提示词（QQ / 微信 / B站 / 桌面通道） | 「别用…这类开头」两句换成**开头三条死规矩**：① 第一句不许「刚/刚刚/刚才/今天/最近」+ 看到/刷到/发现/听说 打头；② 不许交代怎么知道的；③ 不许把由头原句搬过来。并追加**正向示范**（外面下雨了 / 我这会儿在煮面 / 你上次说那事儿弄完没），第一句落到具体场景 |
| `lib/gateway.js` | 抖音私信分享跟话 | 起手禁词扩到「刚看到、刚刷到、刷到个、看到一个、发了条、给你看个、分享个」，并明令别解释是从哪儿翻出来的 |
| `lib/life.js` | 分享由头 `reason` 模板 | 「素材/链接」改成**中性描述**（只说这是啥、别提上一条视频），并加一句「开口别用刚看到/刷到/看到/听说这类起头，直接从里面的细节说起」；顺手修掉混进提示词的多余引号 |
| `lib/social.js` | `bannedOpening` 正则 | 扩到 `刚/刚刚/刚才/今天/最近 + 看到|看见|刷到|发现|听说|瞅见|瞄到`，以及 `看了个|看了段|看到个|看到段`；`openingClash` 兜底改写同步生效 |

## 正则自测

```
BLOCK 看到你就想笑               BLOCK 刷到个猫

pass  楼下那家店关门了            pass  洗到一半没水了
pass  今天下班早                 pass  想吃冰的
pass  你这会儿在干嘛
```
